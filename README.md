# SEIS 606 – Vibe Coding App Ideas

## 1. Prompt Mixer
A workspace for experimenting with AI prompts. Users can change things like context, role, format, tone, and constraints and see how those changes affect the AI's response.

## 2. App Planner
A user starts with a rough software idea and the app asks questions about users, features, constraints, priorities, and ambiguities. It then creates a cleaner project specification.

## 3. Fridge Night
Users enter ingredients they already have along with food preferences and how much effort they want to put into cooking. The app suggests meals that use what is available.

## 4. Local Lens
An app for discovering interesting places nearby that people might normally overlook, such as parks, architecture, trails, historical locations, public art, and unusual shops.

## 5. Decision Board
Users enter several options they are considering along with preferences, constraints, and unknowns. The app organizes the tradeoffs so the user can compare the choices.

## 6. Explain It Differently
If an explanation doesn't make sense, the user can ask the app to explain the same idea using a different approach, such as an example, analogy, simplified explanation, or concrete scenario.

## 7. Memory Map
A private map where users can attach photos, notes, stories, audio, or memories to locations that are meaningful to them.

## 8. What's Changed?
Users provide two versions of code, requirements, policies, or other documents. The app identifies meaningful changes and explains their possible consequences.

## 9. Movie Night
A group enters movie preferences, exclusions, streaming services, available time, and current mood. The app finds common ground and suggests movies the group might enjoy.

## 10. Fix First
A troubleshooting assistant that asks a few diagnostic questions before suggesting a solution. The goal is to distinguish symptoms from likely causes before changing anything.
